Statement on AI Usage

No AI tools were used to produce, or assist in the production of, any of the pages on this site, or any of the documents they link to, with two exceptions:

The photos of the display depicted in the images of the "Swerve" tile show the execution of the BayesianResonance.cpp program I wrote in 2004, in C++ using OpenGL, to help me interactively visualize trajectories inside a 3D probability simplex. I used Claude Code (Sonnet) to quickly do minimal edits to that archaic code so it could compile and run on MacOS Tahoe in 2026, when I took those photos of my display.

The little k-1 logo in the circle at the top of these pages was produced using ChatGPT.
