Statement on AI Usage

No AI tools were used to produce, even in part, any of the pages on this site, or any of the documents or files they link to, with two exceptions:

The photo I took of my desktop display in the "Swerve" tile shows the execution of the BayesianResonance.cpp program I wrote in 2004. I had written it in C++ using OpenGL to help me interactively visualize trajectories inside a 3D probability simplex. Twenty years later, I used Claude Code (Sonnet) to quickly do minimal edits to that archaic code so it could compile and run on MacOS Tahoe in 2026, when I took that photo.

The little k-1 logo in the circle at the top of these pages was produced using ChatGPT, then edited with the help of Claude Code.

(I cannot speak to the AI tool usage in the original production of the Phantom HTML5UP template I adapted, of course.)
